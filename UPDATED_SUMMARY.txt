🤖 БОТ 1: Silent Bot (Молчаливый)
   • Добавляется в чаты проектов
   • Отправляет приветствие
   • Молчит и собирает сообщения в БД
   • Токен: TELEGRAM_BOT_TOKEN

🤖 БОТ 2: Smart Bot (Умный) - ВСЁ В ОДНОМ!
   • ⏰ Анализирует по таймеру (каждые 8 часов)
   • 💾 Проставляет статусы в БД  
   • ✉️  Отправляет уведомления продюсерам
   • 💬 Общается с продюсерами и клиентами
   • 🔍 Различает продюсеров/клиентов
   • 📊 Ищет проекты и отвечает с контекстом
   • Токен: TELEGRAM_PRODUCER_BOT_TOKEN

❌ БЫЛО (неправильно):
   - Producer Agent - отдельный бот только для чата
   - Scheduler - только анализ
   - Нет различия продюсеров/клиентов

✅ СТАЛО (правильно):
   - Smart Bot = анализ + чат + уведомления в ОДНОМ боте
   - Различает продюсеров и клиентов (из БД)
   - Разные промпты для продюсеров и клиентов
   - Ищет проекты и отвечает с контекстом

🚀 КАК ЗАПУСТИТЬ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Обновите .env:
   TELEGRAM_BOT_TOKEN=xxx              # Бот 1 (молчаливый)
   TELEGRAM_PRODUCER_BOT_TOKEN=yyy     # Бот 2 (умный)

2. Создайте таблицы в Supabase (SQL выше)

3. Добавьте продюсеров и клиентов в БД:
   INSERT INTO producers (telegram_id, name) VALUES ('123456', 'Иван');
   INSERT INTO clients (telegram_id, name) VALUES ('789012', 'Клиент А');

4. Запустите:
   docker-compose up -d
   
   ИЛИ локально:
   cd backend && npm install && npm run dev
   cd ai-service && pip install -r requirements.txt && uvicorn src.api:app --reload

Бот 1 (Silent):
1. Добавьте в группу проекта
2. Напишите что-то в группе
3. Проверьте Supabase - должна быть запись в messages

Бот 2 (Smart):
1. Напишите боту от продюсера: /start
   → Должно: приветствие для продюсера
   
2. Напишите боту от клиента: /start
   → Должно: приветствие для клиента
   
3. Продюсер: /analyze
   → Должно: запуск анализа
   
4. Клиент: /analyze
   → Должно: "У вас нет доступа"
   
5. Любой: "Какой статус проекта X?"
   → Должно: поиск проекта и ответ
