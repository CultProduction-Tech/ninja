1. 📖 Прочитайте QUICKSTART.md

2. ⚙️  Настройте .env файл:
   cp .env.example .env
   nano .env  # добавьте свои ключи

3. 🗄️  Создайте таблицы в Supabase
   (SQL скрипты в QUICKSTART.md)

4. 🐳 Запустите через Docker:
   docker-compose up -d

   ИЛИ локально:
   cd backend && npm install && npm run dev
   cd ai-service && pip install -r requirements.txt && uvicorn src.api:app --reload

5. ✅ Проверьте работу:
   curl http://localhost:3000/health
   curl http://localhost:8000/health

6. 🤖 Протестируйте Telegram ботов
